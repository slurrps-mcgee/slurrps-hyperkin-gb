BOX ART FOR THE HOME SCREEN
===========================

The home screen shows a picture next to the selected game. Two ways:

1. Next to the game, with the same name (simplest):
     roms/gba/Golden Sun.gba
     roms/gba/Golden Sun.png

2. Here, in RetroArch's layout (RetroArch's thumbnail packs work as they
   are, e.g. from github.com/libretro-thumbnails):
     Nintendo - Game Boy Advance/Named_Boxarts/Golden Sun.png
     Nintendo - Game Boy Color/Named_Boxarts/...
     Nintendo - Game Boy/Named_Boxarts/...
   The file name is the game's name as the home screen shows it, with
   & * / : ` < > ? \ | replaced by _

PNG files only. Any size works; around 512 x 512 or smaller loads
fastest on the console.
